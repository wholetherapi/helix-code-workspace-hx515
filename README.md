# Helix Reasoning Program - Shared Code Workspace

This repository is the program's shared code workspace.

- `inbox/` - flat artifact inbox kept by program operations. Filenames are free-form (researcher names, unit spellings and cycle labels are not normalised).
- `packages/` - one directory per project code package.
- `registers/` - published program registers.
- `staging/` - working area for register preparation.

Please do not rename files in `inbox/`; register work must copy, not move.
